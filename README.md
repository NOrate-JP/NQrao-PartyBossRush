# のれーとパーティ9 ボスラッシュ

マリオパーティ9の「ボスラッシュ」をブラウザで遊べるように再現したゲームです。
画像は使っていません（キャラ・ボスはすべて図形で描画、効果音もブラウザで合成）。

## あそびかた
- **ひとりであそぶ**：CPUと一緒にプレイ（Firebase不要）
- **ルームをつくる / ルームにはいる**：5文字のルームコードで最大4人までオンライン対戦。足りない人数はCPUが入ります
- コース：中ボスラッシュ（6体）／ボスラッシュ（6体）／オールボスラッシュ（12体）／フリー（1体だけ）
- 各ボス戦の順位で **1位+5 / 2位+3 / 3位+2 / 4位+1** ポイント。合計がいちばん多い人がチャンピオン（同点はミニゲーム得点の合計で比較）

### 操作
| キー | 内容 |
|---|---|
| ←↑↓→ / WASD | いどう・カーソル |
| Z / スペース / Enter | A（ジャンプ・けってい・うつ） |
| X / Shift | B |
| 1〜5 / 0・1 | 番号でえらぶ（ノレ兵・トロッコ・01カウント） |
| マウス / タップ | カード・ハンマーをえらぶ、大砲のねらい |

スマホ・タブレットでは画面に十字キーとA/Bボタンが出ます。

| 3 | ノッレン | バッタン | 01カウントで足場を回して、正面の人以外が背中をヒップドロップ |

| 7 | ノレノレ | プクプク | あわの中のこうらを投げる。たいあたりをよける |
| 8 | レットー | ゲッソー | 大砲でうつ。ノニラ（ウニラ）はうち返せる |

## Firebase の設定（オンライン用）
1. Firebase コンソールでプロジェクトを作成
2. **Authentication** → ログイン方法 → **匿名** を有効にする
3. **Realtime Database** を作成（場所はシンガポール `asia-southeast1` などでOK）
4. Realtime Database の「ルール」に下を貼り付けて公開
   ```json
   {
     "rules": {
       "nbr": {
         "$room": {
           ".read": "auth != null",
           ".write": "auth != null && (!data.exists() || data.child('meta/host').val() === auth.uid)",
           "players": { "$uid": { ".write": "auth != null && auth.uid === $uid" } },
           "inputs":  { "$uid": { ".write": "auth != null && auth.uid === $uid" } }
         }
       }
     }
   }
   ```
5. プロジェクトの設定 → マイアプリ（ウェブ）を追加し、表示された設定値を `js/firebase-config.js` に書き写す（**databaseURL も必須**）
6. GitHub Pages などで公開する場合は、公開URLのドメインを Authentication → 設定 → **承認済みドメイン** に追加

## 公開・ローカル確認
- ES Modules を使っているので、`index.html` をダブルクリック（file://）では動きません
- ローカル確認：このフォルダで `python -m http.server 8000` → `http://localhost:8000/`
- GitHub Pages：このフォルダの中身をリポジトリに置いて Pages を有効にするだけで動きます

## しくみ（メモ）
- ホスト（ルームを作った人）のブラウザがゲームの計算をすべて行い、約12回/秒で状態を Realtime Database に書き込みます。ほかの人はキー入力を送り、届いた状態を描画します
- ホストのタブは開いたままにしてください（裏に回っても動くようにはしていますが、閉じるとルームが解散します）
- プレイ中に抜けた人は自動でCPUに交代します
- 通信量の目安：1人あたり 約10〜20KB/秒（無料枠の範囲で遊べる量です）

## デバッグ用URL
- `?auto=3` … 4番目のボス（キングノレ兵）をすぐ遊ぶ（番号は0〜11、-1で全ボス）
- `?auto=3&cpu=1&skip=1` … CPUだけで観戦（説明画面をとばす）
